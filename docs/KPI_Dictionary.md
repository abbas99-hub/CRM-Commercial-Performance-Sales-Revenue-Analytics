# KPI Dictionary

| KPI | Definition | Why it matters | Suggested action |
|---|---|---|---|
| Won Revenue | Sum of estimated revenue where stage = Closed Won | Measures realized commercial output | Compare with target |
| Total Pipeline | Sum of open opportunity value | Measures available demand | Compare with target |
| Weighted Pipeline | Opportunity value × probability | More realistic forecast view | Identify forecast gap |
| Win Rate | Won opportunities / closed opportunities | Measures conversion effectiveness | Diagnose funnel |
| Average Deal Size | Won revenue / won opportunities | Measures commercial value per win | Assess account strategy |
| Pipeline Coverage | Open pipeline / revenue target | Measures whether enough pipeline exists | Create pipeline |
| Target Achievement | Won revenue / target | Measures target delivery | Reallocate focus |
| Opportunity Age | Today - creation date for open deals | Detects stalled deals | Escalate stale deals |
| Activities / Opportunity | Activity count / open opportunities | Indicates engagement intensity | Inspect under-served pipeline |
| At-Risk Pipeline | Open pipeline with low probability | Highlights forecast risk | Requalify or remove |
| Data Completeness | 1 - quality issues / opportunity rows | Measures trust in reporting | Remediate CRM |
