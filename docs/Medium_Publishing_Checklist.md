# Medium publishing checklist

- Upload the three SVG diagrams from `images/` to Medium or convert them to PNG, then insert them at the matching image placeholders.
- Confirm field names and DAX examples match the included model.
- Label synthetic/sample data and illustrative results clearly.
- Do not imply the dashboard is connected to a production tenant unless true.
- Review Copilot availability requirements in the target tenant.
- Add tags: Commercial Analytics, Microsoft Power BI, Dynamics 365, Dataverse, Business Intelligence.
- Add the public GitHub repository URL after publishing it from your account.
- Preview on desktop and mobile; check code blocks and tables.
